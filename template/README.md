# Course Project Presentation Templates

This folder contains plain Beamer templates using the default sans-serif font for the project presentations in CS460/660 - Machine Learning (2026).

## Presentation schedule

- Presentation 1: 27 Aug 2026
- Presentation 2: 14-15 Sep 2026
- Presentation 3: 26-27 Oct 2026
- Presentation 4: 16-17 Nov 2026

## Slide counts

- Presentation 1: 2 slides
- Presentation 2: 5 slides (P1's 2 slides + 3 update slides)
- Presentation 3: 6 slides (P1's 2 slides + P2 summary + 3 update slides)
- Presentation 4: 10 slides (P1's 2 slides + P2 summary + P3 summary + 6 final slides)
