# CS460/660 - Machine Learning 2026

Course repository for the 2026 Odd Semester.

## Student workflow

1. Create a folder named `student/<your-name>/`. Follow the existing `student/student-name/` layout.
2. Copy the presentation and report templates from `template/` into your folder. Keep both the `.tex` source and compiled `.pdf` for every submission.
3. Replace the placeholder text with your own work. Do not overwrite files in `template/` or another student's folder.
4. Update your row in `index.html` with your name, project title, and links to the submitted PDFs.
5. Commit only your files and the required `index.html` row change, then open a pull request.

## Required submissions

| Milestone | Files | Expected content |
| --- | --- | --- |
| Presentation 1 | PDF and TeX | 2 slides: base paper, existing work, input/output, dataset, research question, and tentative timeline. |
| Presentation 2 | PDF and TeX | 5 slides: reuse P1's two slides; add what you tried, why you tried it, and the updated timeline. |
| Presentation 3 | PDF and TeX | 6 slides: reuse P1; add a P2 summary, results, updates, and remaining questions. |
| Presentation 4 | PDF and TeX | 10 slides: reuse P1, P2 summary, and P3 summary; add final results, analysis, limitations, and conclusion. |
| Midway1, Midway2, Final | PDF and TeX report | Use the two-column report template. Midway reports are one page each; the final report is two pages. |

No report is required for the proposal.

## Pull request checklist

- Your files are inside `student/<your-name>/` only.
- Each linked PDF opens and contains readable content.
- Each PDF has its matching `.tex` source.
- Presentation slide counts are within the stated limits.
- The project row in `index.html` has the correct name, title, and links.
- The pull request title identifies your name and milestone, for example: `Jane Doe: Presentation 2`.

## AI policy

AI tools may be used for assistance, but slides and reports must be prepared manually and the submitted content remains your responsibility. You must be able to explain every part of the work in the viva; inability to explain AI-assisted content may result in zero.
